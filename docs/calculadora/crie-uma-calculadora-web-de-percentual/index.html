Como medir

Meça a cintura sem contrair o abdômen. O pescoço deve ser medido abaixo da laringe, com a fita levemente inclinada para a frente. Para mulheres, o quadril deve ser medido na maior circunferência horizontal.

As fórmulas do método US Navy geram uma estimativa ampla. Para maior precisão, combine o acompanhamento com avaliação profissional e medições consistentes.
